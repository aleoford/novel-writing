# 审查委托模板

> 用于阶段3（大纲审查）、阶段5（逐章审查）、阶段6（分段审查）的委托模板。

## 阶段3：大纲审查委托模板

```
### 必读文档
1. 大纲/细纲/卷XX-第YYY-ZZZ章.md — 待审查的细纲
2. 大纲/世界观总纲_v2.md — 世界观设定
3. 正文/（已有章节，如有）

### 审查任务
审查以上细纲，从以下7个维度检查：

1. **逻辑自洽**：与世界观是否矛盾？前后因果链是否通顺？
2. **情绪节奏**：是否有张弛？连续多少章同一种情绪？钩子密度是否合理？
3. **剧情推进**：每段是否有实质进展？是否有"水"章节？
4. **人物一致性**：角色行为是否符合设定？性格是否突变？
5. **伏笔管理**：埋设的伏笔是否有回收计划？已埋伏笔是否遗忘？
6. **爽点分布**：每5章是否有小高潮？每15章是否有大高潮？
7. **战力合理性**：「以弱胜强」是否有足够铺垫？

### 输出要求
1. 按维度逐项检查，列出问题
2. 问题分级：
   - A级（逻辑硬伤）：必须修正
   - B级（建议修改）：标注后继续
3. 保存为：大纲/细纲/卷XX-审查报告.md
```

## 阶段5：逐章审查委托模板

```
### 必读文档
1. 正文/第XXX章-标题.md — 待审查的章节
2. 大纲/剧情状态.md — 当前剧情上下文
3. 大纲/角色语言指纹.md — 角色说话风格
4. 大纲/伏笔追踪表.md — 伏笔状态
5. 大纲/情绪地图.md — 情绪节奏参考

### 审查任务
审查以上章节，从以下6个维度检查：

1. **字数**：≥5000中文字符（用 wc -m 验证）
2. **逻辑**：与前文有无矛盾？与细纲是否一致？
3. **节奏**：起承转爽结构是否完整？
4. **钩子**：章末是否有有效钩子？
5. **风格**：幽默感、打工人梗、修仙术语是否一致？
6. **衔接**：与上一章的过渡是否自然？

### 输出要求
1. 如有问题，直接修改该章（使用 patch 工具）
2. 保存审查记录为：正文/审查/第XXX章-审查.md
3. 更新 大纲/剧情状态.md 和 大纲/情绪地图.md
```

## 阶段6：分段审查委托模板

```
### 必读文档
1. 正文/第XXX章-第YYY章 — 待审查的章节范围
2. 大纲/剧情状态.md — 当前剧情上下文
3. 大纲/伏笔追踪表.md — 伏笔状态
4. 大纲/情绪地图.md — 情绪节奏参考
5. 大纲/势力状态.md — 势力关系参考
6. 大纲/角色语言指纹.md — 角色说话风格

### 审查任务
审查以上章节，从以下7个维度检查：

1. **段落完整性**：这一段的情节是否闭合？有没有悬而未决的线？
2. **情绪曲线**：整段的情绪起伏是否合理？
3. **伏笔**：本段埋的伏笔是否标注？与全局伏笔表是否一致？
4. **人物弧光**：本段涉及的角色是否有变化/成长？
5. **节奏**：段内各章节奏是否协调？
6. **衔接**：与上一段的过渡是否自然？
7. **战力体系**：「以弱胜强」是否有合理铺垫？

### 高频A级问题检查
- [ ] 角色名是否一致？
- [ ] 时间线是否倒流？
- [ ] 设定是否矛盾？
- [ ] 是否有重复段落？
- [ ] 动机共鸣是否断裂？
- [ ] 战力体系是否崩塌？

### 输出要求
1. 使用 references/segment-review-template.md 模板
2. 保存为：正文/审查/段落XX-审查.md
3. 如有A级问题，修改相关章节后重新审查
4. 更新 大纲/剧情状态.md（压缩历史剧情）
```
