# 世界观构建框架

> 从 no003（碎灵纪）项目中提炼的世界观构建方法论。

## 核心设定三要素

1. **资源稀缺性** — 什么在争夺？谁控制资源？
2. **知识垄断** — 信息如何流通？什么被封锁？
3. **权力结构** — 谁在统治？如何维持？

## 世界观维度清单

构建完整世界观时，需要覆盖以下维度：

### 基础设定
- [ ] 能源/资源体系（灵气、灵石、灵脉）
- [ ] 修炼体系（境界划分、灵根系统、修炼路径）
- [ ] 经济体系（货币、市场、定价权）

### 社会结构
- [ ] 宗门/组织体系（等级、内部运作、晋升机制）
- [ ] 散修/底层生态（收入来源、生存策略、阶层流动）
- [ ] 商会/平台经济（渠道控制、信息不对称）
- [ ] 凡人视角（与修士的关系）

### 冲突与历史
- [ ] 战争体系（谁在打、为什么打、战争形态）
- [ ] 知识传承（为什么残缺、如何垄断）
- [ ] 外部威胁（妖兽、异族、魔族）
- [ ] 历史年表（关键事件、转折点）

### 地理与细节
- [ ] 地理环境（区域划分、关键地点）
- [ ] 传讯手段（信息如何流通）
- [ ] 法宝/丹药/阵法体系

## 逻辑自洽检查清单

构建世界观后，检查以下问题：

1. **资源平衡** — 如果资源衰竭，为什么世界还没崩溃？需要人口消减机制。
2. **货币矛盾** — 如果货币同时是能源，如何处理通胀/通缩？
3. **收入支出** — 底层角色的收入和支出是否自洽？
4. **知识封锁** — 垄断手段是否逻辑完整？残篇如何流通？
5. **人口数据** — 各阶层占比是否合理？加总是否100%？
6. **外部威胁** — 敌对势力是否有内在逻辑？不只是"邪恶"？
7. **组织博弈** — 各势力之间如何制衡？权力是否真空？
8. **阶层流动** — 为什么底层组织没有演变为上层？
9. **数值体系** — 具体数值是否清晰？（灵气浓度、价格、距离）
10. **凡人视角** — 是否忽略了非修炼者？
11. **时间线** — 寿命、修炼时间、窗口期是否合理？

## "打工人"映射模板

将现实社会结构映射到修仙世界：

| 现实 | 修仙世界 | 映射强度检查 |
|------|----------|-------------|
| 工资 | 灵石日薪 | 收入是否被压低？ |
| 住房 | 洞府/客栈 | 是否租不起？ |
| 教育 | 功法传承 | 是否资源不平等？ |
| 医疗 | 丹药 | 是否看不起病？ |
| 就业 | 佣兵任务 | 是否不稳定？ |
| 晋升 | 境界突破 | 是否天花板低？ |
| 社保 | 宗门庇护 | 是否无保障？ |
| 阶层流动 | 散修→宗门 | 是否极难？ |
| 被剥削 | 被当炮灰 | 是否被压榨？ |
| 消费主义 | 灵饰/丹药依赖 | 是否有陷阱？ |
| 社交 | 坊市茶馆 | 是否信息茧房？ |
| 焦虑 | 修炼焦虑 | 是否内卷？ |

## 平行模型协作模式

| 任务 | 模型A（结构型） | 模型B（创意型） |
|------|----------------|----------------|
| 世界观 | 逻辑框架、一致性检查 | 创意扩展、替代方案 |
| 大纲 | 节奏控制、钩子设计 | 情感细节、人物弧线 |
| 正文 | 审查、质量控制 | 主要写作 |
