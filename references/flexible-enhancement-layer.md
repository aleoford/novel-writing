# 弹性增强层设计模式

> 用于风格锚定文档中，替代硬性"每章必加N个"的指标。

## 核心原则

**判断标准 > 数量要求**。每项增强手段都有"什么时候该加"和"什么时候不该加"的判断条件，由AI在写作/审查时自行判断。

## 模板结构

在风格锚定文档中添加以下章节：

```markdown
## 弹性增强层

> 所有规则都是"可选项"。写完一章后，AI 分析章节内容，判断哪些手段适合当前章节，适合就加，不适合就跳过。
> 判断标准：加了是否让读者感受更强？如果只是让文字更花哨，不加。

### 5.1 节奏变奏
- **短句堆叠**：紧张、危险、信息密集的段落
- **长句拖住**：压抑、沉默、重量感的段落
- **判断标准**：这一段的情绪是"快"还是"慢"？

### 5.2 身体反应
- 嗓子干、后背发凉、手指发白、胃里发紧……
- **不标注情绪**：只写症状，不写"他感到紧张/恐惧"
- **判断标准**：这个信息/事件的冲击力够不够大？够大就加，日常推进不需要。

### 5.3 精准比喻
- **判断标准**：这个概念/情绪用直述需要三句话以上？用比喻一句能说清？那就用。
- **频率参考**：一章0-3个。关键章可以多一些，日常章可以没有。
- **禁忌**：不从外面借意象。比喻的原材料必须在故事的世界里。

### 5.4 情绪断层
- 全程冷的基调中，偶尔出现一两行"反常"的软弱/怀旧/犹豫，然后马上掐掉
- **判断标准**：这一章的事件是否足以撼动主角的情感底线？
- **频率参考**：全卷（N章）出现3-5次。宁缺毋滥。
- **写法**：断层只持续1-3行。出现得突然，收得也快。

### 5.5 感官补充
- **判断标准**：这个场景是不是读者需要"身临其境"的重要场景？
- **不堆砌**：一个场景补一两个就够。
```

## 验证清单拆分

```markdown
## 每章验证清单

### 基础项（必检）
- [ ] 开场300字内有钩子？
- [ ] 有至少一个情绪高点或信息揭示？
- [ ] 主角有主动行为（非纯被动反应）？
- [ ] 与上章衔接自然？
- [ ] 角色语言符合指纹？
- [ ] 无禁忌清单中的问题？
- [ ] 结尾有悬念/钩子？
- [ ] 字数在XXXX-XXXX之间？

### 弹性增强项（AI判断，非必检）
- [ ] 本章节奏是否有变化？（全短句 → 找一个关键点插入长句蓄力）
- [ ] 有没有重大信息/事件适合加身体反应？（有 → 加一两个）
- [ ] 有没有用三句话才能说清的概念/情绪？（有 → 试一个精准比喻）
- [ ] 本章是否触及主角情感底线？（是 → 考虑加一处情绪断层）
- [ ] 关键场景是否只有视觉？（是 → 补一个非视觉感官细节）
```

## 适用场景

- 风格诊断发现"太干巴巴"（情绪真空、节奏单调、感官单一）
- 风格诊断发现"太花哨"（修辞堆砌、比喻泛滥、过度煽情）
- 用户要求"优化风格"但不想变成另一种极端

## 设计原因

用户原话："不用必须每章几个，用AI分析哪些适合加的加上就行，不是每章必加。"

硬性指标（"每章必须2个比喻3个身体反应"）会导致：
1. 为了凑数而加，质量下降
2. 不适合的章节被迫加不合适的内容
3. 变成新的形式主义

判断标准让AI根据章节内容自主决策，保持灵活性。
