# 核心设定中途变更工作流

> 当用户要求更换金手指、主角性格、世界观核心设定等根本性变更时使用。

## 触发信号
- "把金手指改成..."
- "主角不是程序员了，改成..."
- "世界观从XX变成YY"

## 流程（6步）

### 1. 确认变更范围
问用户：
- 哪些设定要改？（金手指/世界观/力量体系/角色背景）
- 已写的章节要全部重写还是部分修改？
- 大纲要不要一起改？

### 2. 更新设计文档
先写新设定的详细设计（如 `大纲/力量体系/新设定.md`），包含：
- 核心概念
- 能力描述（输入/输出/限制/成长路径）
- 与旧设定的区别对比表
- 使用场景示例

### 3. 更新大纲和辅助文档
```bash
# 批量替换旧关键词
cd ~/novel/<project>/
sed -i 's/旧设定关键词/新设定关键词/g' 大纲/章节大纲_v1.md
sed -i 's/旧设定关键词/新设定关键词/g' 大纲/剧情状态.md
sed -i 's/旧设定关键词/新设定关键词/g' 大纲/伏笔追踪表.md
# ... 其他需要更新的文档
```

### 4. 清理旧文件
```bash
# 删除所有备份文件夹（用户明确不要）
rm -rf 正文_原始备份/ 正文_重写前备份/ 正文_*备份/
rm -f 润色日志_*.md 风格对比与润色建议.md 总结.md
```

**用户偏好**：不要保留旧版备份，直接重写覆盖。

### 5. 清空正文目录
```bash
rm 正文/*.md
```

### 6. 从头重写
按3章/批的节奏，委托agy从第1章开始重写。每批必须包含：
- 新设定的详细设计文档
- 更新后的大纲
- 更新后的剧情状态文档

## 实战案例：效率优化器 → AI大模型

**变更内容**：
- 旧：效率优化器（自动扫描，无消耗，面板输出）
- 新：AI大模型/第二大脑（需要输入，有灵力消耗，思维提示输出）

**关键设计决策**：
- 新设定有4个限制（输入依赖/计算消耗/训练需求/上下文窗口）
- 成长路径分5个阶段（基础版→完全体）
- 每章必须体现灵力消耗和上下文管理

**影响范围**：
- 全部50章正文重写
- 大纲更新（金手指描述）
- 剧情状态更新（主角能力描述）
- 伏笔追踪表更新（金手指相关伏笔）
- 角色语言指纹更新（思考方式描述）

## 注意事项
- sed批量替换后需要人工检查是否有遗漏或误替换
- 新设定的设计文档必须在重写前完成，否则agy会自行发挥
- 重写时每批3章，不要贪多
