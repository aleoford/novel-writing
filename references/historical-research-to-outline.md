# 历史素材→修仙大纲转化工作流

> 当用户要求"参考某段历史写大纲"时使用此流程。

## 核心原则

1. **历史人物是"顶层设计"**：主角接触不到这些人物，只能接触到他们手下的手下，以及受他们影响的事件
2. **事件通过"传闻→物资变化→人员调动→账目异常"的方式渗入**，不通过"前线战报"直接告诉读者
3. **每一段都落在一个具体物件上**：一张封签、一页账册、一批药材、一份清查令

## 工作流

### 步骤1：历史调研（委托agy）
调研维度：
- 核心人物关系网（谁和谁什么关系）
- 关键战役/事件（具体经过，越详细越好）
- 权力运作的微观细节（财政、腐败、信息不对称）
- 小人物视角素材（普通士兵、地方官员、商人、百姓的遭遇）

### 步骤2：映射关系表
建立历史→修仙世界的映射：

| 历史 | 修仙世界 |
|------|---------|
| 朝廷 | 天衍盟/最高权力机构 |
| 节度使 | 军方势力 |
| 叛军 | 外敌势力 |
| 宦官监军 | 监察使制度 |
| 盐价暴涨 | 灵材价格暴涨 |
| 虚报兵员/吃空饷 | 虚报产量/暗账 |

### 步骤3：事件→阶段映射
将历史事件按时间顺序映射到小说的七个阶段：
- 每个阶段对应1-2个历史事件
- 历史事件不按时间线性展开，而是作为"背景压力"从不同方向渗入

### 步骤4：补充世界观
在世界观圣经中新增映射到的势力和制度。

### 步骤5：写出阶段级大纲（v3版）
在原有大纲框架的基础上，每个阶段注入历史事件的修仙化改编。

## 飞书交付排版规范
- **禁用 Markdown 表格**：在向用户发送的飞书消息中，绝对不要使用 Markdown 格式的表格，排版在消息栏中会被折行或截断，极其混乱。必须将结构对比转换为**列表**、**粗体字段**或**预置代码块**等格式输出。

## 输出文件
- `参考素材/<历史事件名>/历史调研报告.md`
- `大纲/章纲/第X卷大纲_v2_<历史事件名>版.md`
- 世界观圣经更新（新增势力设定）

## 素材转化示例

**陈涛斜之战（外行指挥内行）→ 小说素材**：
- 天衍盟某位文职高层被派去前线指挥，不懂实战
- 监军催促进攻，不给准备时间
- 用了一批"账面上好看但实际不能用"的物资（暗账流出的次品丹药）
- 惨败后责任被推到"后勤供给不足"——黄芽堂首当其冲
- 主角视角：他经手过那批丹药，知道是暗账流出的次品，但没人会查这个

**仆固怀恩被逼反（功臣悲剧）→ 小说素材**：
- 某位军方将领战功赫赫，家族死伤惨重
- 平叛后天衍盟开始削权，监察使进谗言
- 旧部被分化调离，有的被"安排"到黄花丹派附近
- 主角视角：黄芽堂突然多了一批"来历不明"的灵材供应。师傅说"不要问这批货从哪来"

**崇祯决口之战（大同之蔽/崩溃前的寄生收割）→ 小说素材**：
- 核心逻辑：修仙政权（天衍盟）在内外死局（北狄南叛）中，抽调最后的核心资产督修防线（九曲界防决口）。
- 暗账中介：宗门高层 and 运输商假公济私，将珍贵的神砂替换为废砂，导致防线反复崩塌（甚至主动制造崩溃平账，造成“所有物资被卷”的死无对证）。
- 主角视角：主角担任后勤副使，利用这一致命审计风暴做局（用暗账脱身，记录为死人），卷款隐藏于账外安全脱壳。
