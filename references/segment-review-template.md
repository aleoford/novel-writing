## 高频A级问题（实测）

| 问题类型 | 表现 | 修复方式 |
|---------|------|---------|
| 角色名不一致 | 不同批次给同一角色不同名字 | 统一到细纲设定，修改所有出现处 |
| 时间线倒流 | 章节内容时间顺序与编号不符 | 修改时间描述使其与前后章一致 |
| 设定矛盾 | 宿舍人数、地点名称等前后不一 | 以细纲为准，修改不一致的章节 |
| 重复段落 | 迭代扩充时复制粘贴导致 | 删除重复段，补充过渡句 |
| 动机共鸣断裂 | 读者无法理解主角行为的动机 | 补充铺垫或调整设定 |
| 战力体系崩塌 | 以弱胜强缺乏合理解释 | 补充智谋/信息差/道具铺垫 |
